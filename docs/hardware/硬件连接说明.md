# 硬件连接说明

本文档按当前工程源码整理，列出固件实际使用的全部 GPIO、总线与外设地址，用于原理图核对、板卡调试和二次开发。

> **适用板卡：本工程硬件。** GPS LDO EN = P02、总电源开关 = P03。

### 2.1 strapping 引脚提示

GPIO0 / GPIO3 / GPIO45 / GPIO46 是 ESP32-S3 的 strapping 脚，复位瞬间会被采样：

| GPIO | strapping 含义 | 本设计用途 |
| --- | --- | --- |
| 0 | 启动模式 | BOOT 按键（低=按下） |
| 3 | JTAG 信号源选择 | TCA9535 INT（上拉） |
| 45 | VDD_SPI 电压选择 | FT6336U INT（上拉） |
| 46 | ROM 日志输出控制 | 背光 PWM |

硬件需保证复位瞬间这 4 个脚的电平符合启动要求；固件是在启动之后才把它们配置成对应功能的。本版板卡已实测可正常启动。

另外，GPIO39–42（默认 JTAG 引脚）在本设计中全部用于 I2S，因此引脚 JTAG 不可用；调试请使用 ESP32-S3 内置的 USB-JTAG（GPIO19/20）。

因为S3的RST按钮在外壳内部，并未外置单独键帽，
所以装配完成后，如果需要让设备进入烧录模式，方法：按住 boot 按键（锁屏按键）后，长按开关机按键，就可以进入 S3 的烧录模式。
如果设备在运行时意外死机未响应，可以长按开关机按键，使设备物理断电

## 4. I2C0 总线（100 kHz）

| 项目 | 配置 |
| --- | --- |
| 控制器 | `Wire` |
| SCL | GPIO1 |
| SDA | GPIO2 |
| 速率 | 100 kHz |
| 挂载设备数 | 8 |

### 4.1 设备与地址

| 地址（7 位） | 器件 | 功能 | 备注 |
| --- | --- | --- | --- |
| **0x20** | TCA9535 | 16 位 IO 扩展 | 电源、GPS LDO、复位、按键、TF CD，详见第 10 节 |
| **0x2C** | QMC5883P | 三轴地磁计 | 电子罗盘 |
| **0x36** | MAX17055 | 电量计 | 电压 / 电流 / SOC / 充电判断 |
| **0x44** | SHT30 | 温湿度传感器 | 温度、湿度、露点 |
| **0x47** | BMP581 | 气压传感器 | 气压 / 高度 |
| **0x51** | PCF8563T | RTC 实时时钟 | 掉电走时 |
| **0x5A** | DRV2605L | 线性马达驱动 | X 轴 LRA，ROM 波形库 6 |
| **0x6A** | LSM6DS3TR-C | 六轴 IMU | 加速度 + 陀螺 |

> DRV2605L 的 EN 上拉到 VDD，固件不震动时必须写 `MODE.STANDBY=1` 才能省电。
> 初始化和开机提示由 `bsp_haptic` 统一处理：上电默认播放一次 Strong Click
> （Library 6），因为本机没有电源指示灯。提醒强度、提醒效果和触控反馈
> 保存在 NVS `drv2605`，可在自检界面的“震动”页调整；强度 0 会同时关闭开机震动。

### 4.2 总线使用约束

- I2C0 被多个 FreeRTOS 任务并发访问（传感器任务、GPS 任务、UI 任务等），所有事务都由全局递归互斥锁串行化。
- 传感器任务按节拍轮转采样，SHT30 单次测量有约 15 ms 时钟拉伸；渲染路径的按键轮询使用**非阻塞加锁**，总线忙时跳过本次。
- 固件带总线恢复逻辑：连续失败达到阈值时翻转 SCL 释放被拉死的 SDA，并重新初始化 `Wire`，避免必须断电恢复。
- PCF8563T 挂在 **I2C0（Wire）**；其头文件里“Wire1”的注释是笔误，以本表为准。
- SHT30 的 nRESET（TCA9535 P14）上电后保持 HIGH 输出，固件不做单独复位时序。

## 6. LoRa：E28-2G4M20S（SPI3）

| 项目 | 配置 |
| --- | --- |
| 模块 | **E28-2G4M20S** |
| 射频芯片 | SX1280 |
| 频段 | 2402–2482 MHz |
| 调制 | LoRa（CSS） |
| 天线 | 板载 PCB 天线（S 版，装在外壳内，不可拆换） |
| 发射功率 | 默认/推荐 **7 dBm**（EIRP ≈ 9 dBm）；模块硬件上限 **20 dBm** |
| SPI 主机 | **SPI3 / HSPI**（独立于屏幕的 SPI2） |

| 信号 | GPIO | 说明 |
| --- | --- | --- |
| MISO | 4 | — |
| MOSI | 5 | — |
| SCK | 6 | — |
| NSS | 7 | 模块片选 |
| DIO1 | 8 | 收发完成中断；睡眠时用于判断是否有待收数据 |
| RXEN | 15 | 外置 PA 接收使能 |
| TXEN | 16 | 外置 PA 发射使能（必须驱动） |
| NRESET | 17 | 模块复位 |
| BUSY | 18 | 硬件忙检测 |

说明：LoRa 早期与屏幕共用 SPI2，出现过屏幕雪花条纹（总线竞争）。现固定使用 SPI3，两路总线通过 GPIO 矩阵映射，PCB 无需改动。

> **与 WiFi 共存：** 实测 LoRa **7 dBm** 可与 WiFi 同时工作；仅验证了该功率。
> 固件不做 7 dBm 硬限制，可上调到模块硬件上限 20 dBm，高于 7 dBm 时串口只提示。
> LoRa 功率更高时，近距离有损坏 ESP32-S3 LNA 的风险；并发时建议让 LoRa 中心
> 频率远离 WiFi 信道；BLE 未做并发实测，按同频段原则处理。

## 7. GPS：MAX-M10S（UART0）

| 项目 | 配置 |
| --- | --- |
| 模块 | u-blox **MAX-M10S** |
| 协议 | UBX 二进制 |
| 串口 | `Serial0`（UART0） |
| RX（ESP 收） | GPIO44 |
| TX（ESP 发） | GPIO43 |
| 波特率 | **230400**，8N1（最终工作值） |
| 供电 | 由 TCA9535 **P02** 控制 LDO（HIGH=开启） |

- 开机自动识别波特率：230400 → 115200 → 38400，识别后统一配置为 230400 UBX。
- RX 缓冲区设为 2 KB。
- 睡眠流程必须先 `Serial0.flush()` → `Serial0.end()` → 再关 GPS LDO；顺序反了会让 UART TX 中断打到已断电外设，触发看门狗复位。

## 9. 音频：I2S0 全双工

| 项目 | 配置 |
| --- | --- |
| I2S 端口 | I2S_NUM_0 |
| 模式 | 主机，TX + RX 全双工 |
| 采样率 | 默认 8000 Hz（`BSP_I2S_SAMPLE_RATE`；可用 `bsp_audio_set_sample_rate()` 运行时调整） |
| 位宽 | 32 bit |
| 声道格式 | 立体声（左右） |

| BCLK | 默认 8000 × 64 = 512 kHz |

| 信号 | GPIO | 对端 |
| --- | --- | --- |
| BCLK | 38 | MAX98357A BCLK / ZTS6672 BCLK |

## 10. TCA9535 IO 扩展器

| 项目 | 配置 |
| --- | --- |
| 器件 | TCA9535 |
| 地址 | **0x20**（7 位） |
| 总线 | I2C0（GPIO1/2，100 kHz） |
| INT | GPIO3，下降沿，上拉 |
| 复位脚 | **无**（芯片没有 RESET 引脚） |

### 10.1 引脚分配

| 芯片引脚 | 库索引 | 功能 | 上电后方向 | 有效电平 |
| --- | --- | --- | --- | --- |
| P00 | 0 | 音量减按键 | 输入 | 低=按下（外部上拉） |
| P01 | 1 | 音量加按键 | 输入 | 低=按下（外部上拉） |
| P02 | 2 | GPS LDO 使能 | 输出 | **HIGH=开启** |
| P03 | 3 | 总电源开关 | 输出 | **HIGH=运行 / LOW=关机** |
| P10 | 8 | 硬件版本脚 | 输入（不驱动） | 10K 上拉 |
| P14 | 12 | SHT30 nRESET | 输出 | HIGH=正常运行，低有效 |
| P15 | 13 | 触摸屏 RST | 输出 | HIGH=正常，LOW=复位 |
| P16 | 14 | 显示屏 RST | 输出 | HIGH=正常，LOW=复位 |
| P17 | 15 | TF 卡 CD | 输入 | **低=已插入** |

> 命名注意：库里的 `TCA_P10` 表示“端口 1 的第 0 位”，对应引脚索引 **8**，不是“引脚 10”。同理 P14–P17 的索引是 12–15。

### 10.2 上电初始化顺序（重要）

固件在初始化时先写输出寄存器、再切换方向：

1. `write16(0xFFFF)`：先把输出寄存器写成全 HIGH（此时引脚仍是输入，不影响实际电平）。
2. `pinMode16(1 << P10)`：只把 P10 留作输入，其余全部切换为输出。

这样引脚从高阻直接变为目标电平，不会出现低电平毛刺。**不能使用库的 `begin(OUTPUT, mask)`**——它内部先切方向再写电平，中间会短暂输出默认低电平；本板总电源开关为高有效，这个毛刺会直接拉低 P03 导致整机断电。

初始化后 P17、P00、P01 再单独配置为输入。

### 10.3 无复位脚带来的约束

TCA9535 没有 RESET 引脚：冷上电时寄存器为全输入，但**热复位**（panic、看门狗 `esp_restart()`、串口烧录）时 3.4 V 不掉电，芯片会保留上一次的输出和方向配置。因此固件不能假设“上电即默认状态”，必须按上面的顺序显式重配；P10 也始终只作输入，避免热复位时被上一次的输出去驱动版本脚。

### 10.4 关机

软件关机的实现是把 **P03 输出 LOW**，经 AO3401 控制 GEK100 的 RST，切断 TPS63802 的 EN，整机硬掉电。P03 一旦为低就不可恢复，只能重新上电。
