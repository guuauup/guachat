二、设计目标与核心约束
2.1 设计目标
稳定性：3.4V母线全负载范围内稳定，E28-2G4M20S 20dBm发射时VCC ≥ 3.3V（20dBm为模块硬件峰值能力；固件默认 7dBm，允许上调至 20dBm，高于 7dBm 只提示风险。保留 20dBm 供电能力，后续 SRRC 整机认证时无需改动硬件）。

低噪声：ZTS6672数字麦底噪 ≤ -64dB SNR，音频等大电流负载分时工作；LoRa/WiFi 并发条件见 2.3 节。

安全性：上电无浪涌过流，适配-20℃ ~ +70℃工作环境。

BOM精简：统一磁珠选型为 TDK MPZ2012S601A，减少物料种类。

2.2 核心前提（电源设计约束）
分时工作：音频录/播仍严格串行；LoRa 与 WiFi/BLE 并发时，建议按 2.3 节的频率与功耗条件评估。

射频共存：实测 LoRa **7 dBm** 可与 WiFi 同时工作；**LoRa 功率更高时，近距离有损坏 ESP32-S3 LNA 的风险**。固件不硬限制 7 dBm，高于推荐值只提示，是否并发高功率由使用者自行评估。并发时建议 LoRa 中心频率远离 WiFi 信道。

电池规格：开源硬件为单节 18650，4.4V / 5200mAh；输入电压范围 2.8V（放电截止）~ 4.4V（满电）。

电池策略：推荐电池（4.4V / 5200mAh）建议应用层在 **低于 3.40V 时自动关机**，基线取 **3.30V**；3.40V 以下剩余容量已经很少。关机后 HT7125S 仍可从电池保护电路后取电，为 GPS 模块和 RTC 提供 **>30 天**备用电源。

### 2.3 射频共存实测（2026-10-26）

- **已验证：LoRa 7 dBm 与 WiFi 可同时工作。**
- 仅验证了 7 dBm。更高 LoRa 功率近距离可能损坏 ESP32-S3 的 LNA；固件只提示、不阻止，风险由使用者自行评估。
- 并发建议：LoRa 中心频率远离 WiFi 信道，至少避开 WiFi 的 20 MHz 占用带宽并留保护带；最终以丢包率和吞吐实测为准。默认 2405 MHz 靠近 WiFi ch1（2412 MHz），WiFi 用 ch1 时建议改到远离该信道的频率。
- BLE 与 WiFi 同属 2.4 GHz，但 BLE 未做并发实测，按同样原则处理。
- 无法满足频率隔离时，建议按分时工作。

核心变更说明：

DCDC输出到L3之间不串1µH电感，避免影响环路稳定性。

主Bulk电容（220µF） 就近放置在 E28模块VCC引脚旁，用于应对20dBm发射时的140mA突发电流。

所有大电流负载统一使用 TDK MPZ2012S601A 磁珠（600Ω/2A/0.1Ω）。

I2C设备直接从磁珠前的3.4V电源层取电，避免被ESP32-S3的噪声干扰。

五、统一磁珠选型
为简化BOM管理，所有大电流负载统一使用一颗磁珠：

参数	规格
型号	TDK MPZ2012S601A
封装	0805 (2012公制)
阻抗 @ 100MHz	600Ω
额定电流	2A
直流电阻（DCR）	0.1Ω (最大)
选型理由：

600Ω阻抗能有效抑制100MHz ~ 1GHz频段噪声。

2A额定电流远高于各负载实际峰值电流（140mA max），余量充足。

0.1Ω DCR在最坏情况（140mA）下仅产生约14mV压降，可忽略不计。

六、各路负载详细电源规划
6.1 ESP32-S3 WROOM
项目	配置
电压要求	3.0 ~ 3.6V
峰值电流	~340mA（WiFi发射）
磁珠	MPZ2012S601A（600Ω/2A/0.1Ω）
本地π型滤波	10µF + 1µF + 100nF MLCC（紧贴模组VCC引脚）
取电路径	L3 → 磁珠 → π型滤波 → 模组VCC
GND规则	所有电容GND端单独打过孔回L2
6.2 E28-2G4M20S（20dBm LoRA PA）
项目	配置
电压要求	≥ 3.3V（20dBm发射临界值）
峰值电流	140mA
实际发射功率	固件默认/推荐 7dBm，可上调至模块硬件上限 20dBm；本表按 20dBm 峰值设计与验证，作为后续 SRRC 整机认证的硬件余量
磁珠	MPZ2012S601A（600Ω/2A/0.1Ω）
本地π型滤波	22µF × 3 + 0.1µF MLCC（紧贴VCC引脚）
主Bulk电容	Lelon OVZ221M0JTR 220µF/6.3V（就近放置在E28 VCC旁）
取电路径	L3 → 磁珠 → π型滤波 → Bulk电容 → E28 VCC
GND规则	所有电容GND端单独打过孔回L2，不与功放GND共用
设计余量	峰值压降 = 140mA × 0.1Ω = 14mV，突发电流由220µF就地供应，VCC跌落可控

说明：140mA 为 E28-2G4M20S 在 20dBm 峰值功率下的电流，属设计冗余。当前固件默认/推荐 7dBm，允许上调至 20dBm；高于 7dBm 只打印风险提示。保留 20dBm 供电能力，是为了后续 SRRC 整机认证时无需改动电源硬件。
6.3 MAX98357A（Class-D功放）
项目	配置
电压要求	2.5 ~ 5.5V（宽压，压降容忍度高）
峰值电流	~350mA（驱动8Ω/1W喇叭，播放音频）
磁珠	MPZ2012S601A（600Ω/2A/0.1Ω）
本地π型滤波	22µF × 3 + 1µF + 0.1µF MLCC（紧贴VCC引脚）
取电路径	L3 → 磁珠 → π型滤波 → 功放VDD
GND规则	所有电容GND端单独打过孔回L2
设计余量	峰值压降 = 350mA × 0.1Ω = 35mV，VCC >> 2.5V，余量充裕
6.4 ZTS6672（数字麦）
项目	配置
电压要求	1.6 ~ 3.6V（宽压）
静态电流	~1mA
磁珠	MPZ2012S601A（600Ω/2A/0.1Ω）
本地π型滤波	22µF × 3 + 0.1µF MLCC（紧贴VDD引脚）
取电路径	L3 → 磁珠 → π型滤波 → 麦VDD
GND规则	电容GND端单独打过孔回L2，麦下方L3/L2铜皮避让声孔
设计余量	压降 = 1mA × 0.1Ω = 0.1mV，纹波可忽略，保障-64dB SNR
6.5 I2C设备（IO扩展、传感器等）
项目	配置
供电方案	直接从磁珠前的3.4V电源层取电（不经过ESP32-S3的磁珠）
取电路径	L3 → 过孔 → 设备VCC
本地去耦	每个设备VCC引脚旁放置 0.1µF + 10µF MLCC
设计理由	避免ESP32-S3的射频噪声通过共用电网传导至I2C设备，影响传感器精度或通信稳定性
七、电源分配网络（PDN）规则
7.1 内电层规则
L3为整面3.4V电源层，无信号线跨分割，不做任何槽口。

高速信号（I2S、射频走线）优先走在L1/L4，参考L2 GND平面。

所有3.4V取电过孔直接从L3引出，禁止在L1上做长距离电源走线后再下L3。

7.2 过孔分配（按电流等级）
负载	取电过孔数量	GND过孔数量	依据
E28 LoRA	2个	2个	峰值140mA，单过孔载流按1A设计，冗余约7倍
MAX98357A	3个	3个	峰值350mA，增加冗余
ZTS6672 麦	1个	1个	静态1mA，单过孔足够
ESP32-S3	2个	2个	峰值340mA
I2C设备	1个/设备	1个/设备	电流≤50mA
八、关键设计约束（DRC必查）
电容GND回路规则：所有π型滤波电容、Bulk电容的GND端必须单独打过孔回L2，禁止多个电容共用同一个GND过孔。

磁珠位置规则：严格遵循 L3过孔 → 磁珠 → π型滤波 → 负载VDD 的顺序。

MLCC选型规则：所有22µF MLCC必须选 6.3V X5R/X7R 材质，3.4V偏压下有效容值 ≥ 额定值的50%。

磁珠后电容不得省略：即使DCDC输出端已有大电容，每个负载磁珠后端必须放置本地π型滤波电容。

I2C设备供电：必须从磁珠前的L3直接取电，不得与ESP32-S3共用磁珠后的电源。

十、验证要求
板子回板后需完成以下测试：

上电浪涌测试：示波器AC耦合测TPS63802输出，上电瞬间无掉压、无反复重启。

静态电压测试：空载时3.4V母线电压 3.38 ~ 3.42V。

动态压降测试：

E28 20dBm连续发射时，VCC脚电压 ≥ 3.3V。

功放播放1W音频时，VCC脚电压 ≥ 3.2V。

麦工作时，VDD纹波 ≤ 5mVpp。

互扰测试：

录音时播放TTS，麦底噪无明显抬升，SNR ≥ 64dB。

LoRA TX时，功放无杂音，麦无底噪抬升。
